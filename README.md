## Selected work

### 🧑‍💻 FirstJob — Job Portal

A full-stack job portal built with **React.js, Node.js, Express.js, and MongoDB**.

- Responsive interfaces for browsing jobs and managing applications.
- RESTful APIs for users, job listings, and application data.
- Secure authentication using JWT and OAuth.

[Live Website](https://first-job-portal.vercel.app/) · [Source Code](https://github.com/shubhamrai11/firstJob-Portal-/)

### 🛍️ Chao — Luxury Fashion Store

A custom **Shopify** storefront built with **Liquid, HTML, CSS, and JavaScript**.

- Responsive storefront tailored to a luxury clothing brand.
- A co-ord builder for pairing tops and bottoms with automatic set discounts.
- Quick-add shopping directly from product cards.

[Visit Store](https://www.shopchao.in/)
